# IOS Projects

## О проекте

**IOS Projects** — это репозиторий, объединяющий все лабораторные и домашние работы, выполненные в рамках курса **«Разработка мобильных приложений под iOS»**.

Каждый проект посвящён изучению отдельной темы разработки под iOS: от создания простых экранов до построения полноценного приложения с навигацией, работой с сетью и архитектурой.

Главная цель репозитория — показать процесс освоения платформы iOS, языка Swift и фреймворка UIKit.

---

## Цель проекта

В рамках курса было необходимо познакомиться с основными инструментами разработки мобильных приложений и научиться создавать пользовательские интерфейсы, работать с жизненным циклом приложения, навигацией между экранами и взаимодействием с данными.

Каждая домашняя работа представляет собой самостоятельное приложение, посвящённое определённой теме.

## Выполненные работы

### IOS_HW1

Изучение базовых возможностей языка Swift и среды разработки Xcode.

Основные темы:

- знакомство со структурой iOS-проекта;
- создание первого приложения;
- работа с элементами интерфейса;
- использование Storyboard;
- основы Auto Layout.

---

### IOS_HW2

Работа с пользовательским интерфейсом.

Изучены:

- UILabel
- UIButton
- UITextField
- UIImageView
- StackView
- Constraints

Реализовано построение адаптивного интерфейса.

---

### IOS_HW3

Работа с навигацией между экранами.

Изучены:

- UINavigationController;
- переходы между ViewController;
- передача данных;
- жизненный цикл ViewController.

---

### IOS_HW4

Создание более сложного пользовательского интерфейса.

Использованы:

- UITableView;
- UICollectionView;
- кастомные ячейки;
- работа со списками данных.

---

### IOS_HW5

В проекте были объединены знания, полученные на предыдущих этапах:

- архитектура приложения;
- работа с моделями данных;
- организация структуры проекта;
- обработка пользовательских действий;
- взаимодействие между экранами.
